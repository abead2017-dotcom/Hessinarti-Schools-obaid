# بناء تطبيق Android

ينشئ سير العمل في GitHub ملف APK موقّعًا بمفتاح الاختبار لاستخدامه في التثبيت اليدوي. هذا مناسب للتجربة الداخلية، وليس إصدارًا جاهزًا للنشر في Google Play.

## خطوات التنزيل

1. ارفع المشروع إلى مستودع GitHub.
2. عند الدفع إلى فرع `main`، يبدأ البناء تلقائيًا. ويمكن تشغيله يدويًا من **Actions → Build Android APK → Run workflow**.
3. بعد نجاح البناء، افتح صفحة التشغيل ونزّل العنصر **hussinarti-android-apk**.
4. فك ضغط الملف وثبّت `app-debug.apk` على هاتف Android. قد يطلب الهاتف السماح بالتثبيت من المصدر الذي نزّلت منه الملف.

## عنوان الخادم

يستخدم البناء افتراضيًا عنوان الإنتاج الحالي. إذا تغيّر لاحقًا، أضف متغير GitHub Actions باسم `EXPO_PUBLIC_DOMAIN` واكتب اسم المضيف فقط، من دون `https://` أو مسار.

يتطلب البناء اتصالًا بالإنترنت لتنزيل تبعيات Android وGradle. ويستمر تسجيل الدخول باستخدام حسابات المنصة الموجودة؛ لا ينشئ هذا البناء حسابات جديدة.
