---
name: Parent portal access
description: Parent account creation, student linking, and child-data access rules for the school platform.
---

School administrators create parent accounts and manage each parent-to-student link. Parents do not self-register as parents or edit those links themselves.

**Why:** A parent link grants access to a student's academic records, so enrollment and relationship changes must remain under school control.

**How to apply:** Keep relationship management admin-only, and verify the authenticated parent's link on the server for every endpoint that returns a student's private data.
